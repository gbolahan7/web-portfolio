# 💼 Web Portfolio

A clean, responsive personal web portfolio built with vanilla HTML, CSS and JavaScript. This repository contains the source for a single-page portfolio that showcases projects, skills, and contact information. It is intentionally simple so it’s easy to customize, extend, and deploy.

## Features

- Single-page layout using `index.html`
- Responsive design with `style.css` and `mediaqueries.css`
- Lightweight interactivity via `script.js`
- Static assets (images, icons) stored in the `assets/` folder
- No build step — open `index.html` or serve with any static file server

## 🚀 Tech stack

- HTML5
- CSS3 (responsive design & media queries)
- JavaScript (vanilla)
